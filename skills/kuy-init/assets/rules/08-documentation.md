# Documentation

- Change the documentation in the same change as the behaviour it describes (README, API contracts, runbooks, comments).
- Keep documents short and link instead of copying; one fact lives in one place.
- Record significant decisions as a short ADR: context, decision, consequence.
- Every `.md` under `.agents/` follows [[rules/14-wikilinks]].
- Write documentation in the language the team already uses for it.
